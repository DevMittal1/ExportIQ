Standard Incoterms 2020 Allocation Matrix

Term Seller Obligation Buyer Obligation Risk Transfer Point
FOB (Free on Board) Export packaging, origin customs clearance, loading goods onto vessel Ocean freight, import tariffs, destination clearance, onward haulage When goods are loaded on board the vessel at origin port
CIF (Cost, Insurance & Freight) Ocean transport and minimum maritime cargo insurance to named port Import duties, VAT, destination port charges, customs import filing When goods pass ship rail at departure port (insurance remains in place)
DAP (Delivered at Place) Complete transit to buyer's named destination place, ready for unloading Import taxes, customs brokerage, unloading at final destination facility When goods placed at disposal of buyer on arriving means of transport
DDP (Delivered Duty Paid) Maximum seller risk: all freight, import clearance, customs tariffs, delivery Unloading goods at destination premises (zero import liability) When goods delivered cleared for import at specified buyer premises

Mandatory Customs Documentation Schedule

Document Purpose & Compliance Scope Requirement Threshold
Commercial Invoice Establishes transaction value for customs valuation, currency, Incoterms, and payment terms Mandatory for all formal commercial shipments
Packing List (P/L) Gross/net weights, container markings, pallet counts, cargo dimensions Mandatory at both export and import customs border posts
Certificate of Origin (CoO) Validates manufacturing provenance for preferential FTA tariff claims vs MFN rates Required for preferential duties or anti-dumping checks
SPS / Phytosanitary Certificate Attests compliance with sanitary and phytosanitary agricultural standards (WTO SPS) Food, plant products, live agricultural cargo
